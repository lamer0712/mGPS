# mGPS Web

GitHub Pages에서 제공하는 휴대폰용 Mock GPS 송신 화면입니다.

배포 주소:

`https://lamer0712.github.io/mGPS/`

AAOS 앱의 QR을 스캔하면 고정 Tailcat 주소가 자동 입력됩니다. 포트는 8787로 고정입니다. iPhone Safari 또는 Android Chrome에서 GPS를 AAOS로 전송하며, 브라우저 GPS 권한을 위해 HTTPS 환경에서 실행됩니다.

여러 휴대폰이 연결된 경우 마지막으로 **전송 시작**을 누른 휴대폰만 GPS를 보낼 수 있습니다. 이전 휴대폰의 전송은 거부됩니다. AAOS 앱과 웹페이지를 모두 최신 버전으로 사용하세요.
